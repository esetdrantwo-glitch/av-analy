# تحلیل‌گر لاگ آنتی‌ویروس / EDR

یک برنامه دسکتاپ ویندوزی (رابط گرافیکی) که لاگ‌های خروجی از آنتی‌ویروس‌ها و ابزارهای
EDR رو می‌گیره، به‌صورت خودکار فرمتش رو تشخیص می‌ده، تحلیل می‌کنه و برای هر رویداد
توضیح کامل فارسی + سطح ریسک + پیشنهاد اقدام تولید می‌کنه.

## چه فرمت‌هایی پشتیبانی می‌شن؟

- **Windows Defender** — خروجی CSV/JSON از `Get-MpThreatDetection` یا Export لاگ رویداد
- **CrowdStrike Falcon** — CSV/JSON دیتکشن‌ها
- **SentinelOne** — CSV/JSON تهدیدها
- **VMware Carbon Black** — JSON هشدارها
- **هر فرمت دیگر** — فایل CSV، JSON یا متنی/لاگ خط‌به‌خط؛ برنامه با تشخیص هوشمند
  نام ستون‌ها (مثل timestamp/severity/threat/action/host/hash) سعی می‌کنه رویدادها رو
  استخراج کنه، حتی اگر محصول را نشناسد.

می‌تونید چند فایل با فرمت‌های مختلف رو هم‌زمان بارگذاری کنید؛ همه با هم در یک
داشبورد ترکیب و تحلیل می‌شن.

## چه چیزی تحویل می‌ده؟

1. **خلاصه و آمار**: وضعیت کلی (عادی / نیازمند توجه / بحرانی)، توزیع شدت،
   وضعیت مهار تهدیدها، پرتکرارترین تهدیدها، میزبان‌های درگیر و تاکتیک‌های
   MITRE ATT&CK مشاهده‌شده (به‌صورت حدسی بر اساس کلیدواژه).
2. **جدول کامل رویدادها**: قابل مرتب‌سازی، با کلیک روی هر ردیف توضیح کامل آن
   رویداد (چه اتفاقی افتاده، چرا مهم است، آیا مهار شده یا نه) نمایش داده می‌شود.
3. **اولویت‌ها و توصیه‌ها**: پراهمیت‌ترین رویدادها به‌همراه اقدام پیشنهادی مشخص
   (مثلاً ایزوله کردن سیستم، ریست رمز عبور، بررسی بکاپ‌ها و...).
4. **خروجی گزارش HTML**: یک فایل گزارش کامل و قابل چاپ/اشتراک‌گذاری با مدیر
   یا تیم امنیتی.

> ⚠️ نکته مهم: تطبیق‌های MITRE ATT&CK و امتیاز ریسک بر پایه‌ی الگوها و
> کلیدواژه‌های رایج هستند (heuristic) و جایگزین تحلیل یک کارشناس امنیت
> اطلاعات نیستند؛ برای رویدادهای بحرانی حتماً بررسی تخصصی انجام دهید.

## نحوه اجرا (روی ویندوز)

### روش ۱: اجرای مستقیم با پایتون (پیشنهادی برای شروع سریع)

1. اگر پایتون ندارید، از [python.org](https://www.python.org/downloads/windows/)
   نسخه ۳.۹ به بالا رو نصب کنید (گزینه "Add python.exe to PATH" رو تیک بزنید).
   کتابخانه `tkinter` که برای رابط گرافیکی لازمه، به‌صورت پیش‌فرض همراه نصب‌کننده‌ی
   رسمی پایتون ویندوز میاد و نیازی به نصب جداگانه نداره.
2. تمام فایل‌های این پوشه (`main.py`, `parsers.py`, `analyzer.py`, `report.py`)
   رو در یک پوشه کنار هم قرار بدید.
3. با دابل‌کلیک روی `main.py` یا از خط فرمان:
   ```
   python main.py
   ```

هیچ کتابخانه‌ی اضافه‌ای (pip install) لازم نیست — همه‌چیز با کتابخانه استاندارد
پایتون نوشته شده.

### روش ۲: ساخت یک فایل اجرایی مستقل (.exe)

اگر می‌خواید بدون نیاز به نصب پایتون روی سیستم‌های دیگه اجرا بشه، یک فایل exe
واقعی بسازید. **این کار حتماً باید روی خود ویندوز انجام بشه** — PyInstaller
نمی‌تونه از لینوکس/مک برای ویندوز کراس-کامپایل کنه، به همین دلیل نمی‌شه یک
exe آماده همراه این پروژه تحویل داد.

**ساده‌ترین راه:** روی فایل `build_exe.bat` (کنار همین فایل‌ها) دابل‌کلیک کنید.
این اسکریپت به‌صورت خودکار:
1. وجود پایتون رو چک می‌کنه،
2. کتابخانه PyInstaller رو نصب می‌کنه،
3. فایل `AV-EDR-Analyzer.exe` رو می‌سازه و مسیرش رو نشون می‌ده
   (معمولاً در پوشه `dist`).

یا اگه ترجیح می‌دید دستی انجام بدید:
```
pip install pyinstaller
pyinstaller --onefile --windowed --name AV-EDR-Analyzer main.py
```

فایل اجرایی نهایی در پوشه `dist\AV-EDR-Analyzer.exe` ساخته می‌شه. بعد از ساخت،
همین یک فایل exe رو می‌تونید به هر سیستم ویندوزی دیگه هم کپی کنید و بدون نیاز
به نصب پایتون روی اون اجرا کنید.

### روش ۳: ساخت exe بدون نصب پایتون روی سیستم خودتون (با GitHub، رایگان)

اگه اصلاً نمی‌خواید پایتون رو روی ویندوز خودتون نصب کنید، می‌تونید بذارید
GitHub (به‌صورت رایگان و در فضای ابری) exe رو براتون بسازه. توی این پروژه
یک فایل آماده در مسیر `.github/workflows/build.yml` گذاشته شده که این کار
رو خودکار انجام می‌ده.

مراحل:
1. یک حساب رایگان در [github.com](https://github.com) بسازید (اگه ندارید).
2. یک "New repository" بسازید (می‌تونه Private باشه).
3. تمام فایل‌های این پوشه (`main.py`, `parsers.py`, `analyzer.py`, `report.py`,
   پوشه `.github`) رو در اون مخزن آپلود کنید — از دکمه
   "Add file → Upload files" در صفحه وب گیت‌هاب استفاده کنید (نیازی به نصب
   Git یا خط فرمان نیست).
4. بعد از آپلود، به تب **Actions** مخزن برید. یک workflow به نام
   "Build Windows EXE" باید به‌صورت خودکار اجرا بشه (یا اگه اجرا نشد،
   خودتون روی "Run workflow" کلیک کنید).
5. صبر کنید (حدود ۱-۲ دقیقه) تا اجرا به پایان برسه (علامت ✅ سبز).
6. روی همون اجرا کلیک کنید؛ پایین صفحه بخش **Artifacts** یک فایل به نام
   `AV-EDR-Analyzer-windows-exe` می‌بینید — دانلودش کنید. داخلش
   `AV-EDR-Analyzer.exe` واقعیه که مستقیم روی هر ویندوزی اجرا می‌شه،
   بدون نیاز به نصب پایتون.

این روش دقیقاً همون کاری رو می‌کنه که `build_exe.bat` می‌کرد، با این تفاوت
که پایتون و PyInstaller روی سرورهای گیت‌هاب اجرا می‌شن، نه روی سیستم شما.

## نحوه استفاده

1. برنامه رو اجرا کنید.
2. از دکمه «+ افزودن فایل لاگ» یک یا چند فایل CSV/JSON/TXT انتخاب کنید.
3. تحلیل به‌صورت خودکار انجام می‌شه؛ بین سه تب «خلاصه و آمار»، «جدول رویدادها»
   و «اولویت‌ها و توصیه‌ها» جابه‌جا بشید.
4. با دکمه «خروجی HTML» یک گزارش کامل برای ذخیره یا ارسال به تیم بگیرید.

## چگونه لاگ خروجی بگیرم؟

- **Windows Defender** (پاورشل با دسترسی Admin):
  ```powershell
  Get-MpThreatDetection | Export-Csv -Path defender_log.csv -NoTypeInformation
  ```
- **CrowdStrike Falcon**: از کنسول Falcon → Detections → Export to CSV/JSON
- **SentinelOne**: از کنسول → Threats → Export
- **Carbon Black**: از API یا کنسول Alerts → Export JSON

## ساختار پروژه

```
av_edr_analyzer/
├── main.py       # رابط گرافیکی (Tkinter)
├── parsers.py     # تشخیص فرمت و استخراج رویدادها
├── analyzer.py    # امتیازدهی ریسک، تطبیق MITRE، توضیح فارسی
├── report.py      # تولید گزارش HTML
└── README.md
```

## محدودیت‌های شناخته‌شده

- تشخیص فرمت برای منابع ناشناخته بر پایه‌ی حدس نام ستون‌هاست؛ در فرمت‌های
  بسیار غیرمعمول ممکنه برخی فیلدها استخراج نشن (اما خود رویداد باز هم نمایش
  داده می‌شه).
- نمایش متن فارسی/عربی در برخی نسخه‌های قدیمی ویندوز/پایتون ممکنه چینش
  راست‌به‌چپ کامل نداشته باشه (به‌خصوص در پنجره‌های قدیمی‌تر Tk)؛ در ویندوز ۱۰/۱۱
  با پایتون به‌روز معمولاً مشکلی نیست.
